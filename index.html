Machine LearningUNSW Research

Financial Market Forecasting

Compared ARIMA, GARCH and multivariate LSTM approaches while preserving temporal ordering and examining where aggregate metrics hide regime-specific weakness.

LSTMARIMAGARCH
Result: LSTM RMSE 12.83, MAE 8.37 and R² 0.9573 versus ARIMA RMSE 16.26 and MAE 12.55. The more useful finding was that performance still weakened during volatility spikes, motivating a hybrid LSTM-GARCH direction.

Event-Driven Integration with Kafka

Python producers and consumers, partitioning, entity-level ordering, idempotent processing and replay-safe patterns for streaming data.

KafkaPythonStreaming
Design choice: used business identifiers as partition keys to preserve ordering per entity, unique event IDs for idempotency, and offset commits only after successful processing so events could be replayed safely.
